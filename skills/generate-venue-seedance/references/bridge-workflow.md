# Bridge an accepted pair of clips

1. Inspect the end of the first clip and start of the next. Record input hashes, actual frame rate, resolution and boundary timestamps. Extract the last/first decoded frames without changing the source videos. Do not assume seeking to the container duration returns a frame.
2. Check whether a hard join or trim already meets the requested continuity. If a passage is missing, generate only that passage. Choose duration from the distance, walking pace and the selected mode's actual limits; do not inherit a previous project's duration.
3. Verify separate start and end image slots, any additional plan-reference support, duration controls and the exact current quote. Label a video edit, Extend, reference-video generation and start/end-frame interpolation as different modes. If only images are supported, state that precise camera-guide following is unavailable.
4. Populate `templates/bridge.txt` with `templates/bridge.values.example.json`. Name the actual files and their roles. Describe the route and time intervals from the inspected evidence. If a plan is attached, identify its real opening and explain that route annotations must not appear in the output. Otherwise omit all plan/red-line references and record any unknown intermediate geometry outside the prompt.
5. Request an immediate continuation, gradual heading changes, level eye height, rigid architecture, preserved furniture and a stop at the target composition. Do not start the following clip's scan or continue past its first viewpoint. Prompt instructions are targets for review, not guarantees.
6. Review the generated clip at both joins and throughout the crossing: composition, heading, velocity, doorway clearance, furniture identity, exposure and duration. Reject a visually attractive shortcut through glazing or furniture. Keep accepted source clips unchanged; regenerate only within existing cost authority.
7. Hand the accepted bridge and explicit trims to the finishing stage. Inspect duplicate endpoint frames for a pause at each join. Record any trim and resulting total duration. Do not hide a spatial discontinuity with a dissolve.
