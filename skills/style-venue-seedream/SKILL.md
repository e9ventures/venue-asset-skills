# Style Venue with Seedream

Use Seedream to style an accepted geometry view using the current property's reference photos. Inspect every reference and assign one role: composition/geometry, material/furniture category, lighting/exterior context. Prepare templates/seedream.txt using pipeline.py prompt and project-specific values. Name the attached inputs explicitly in the rendered prompt. Do not reuse previous venue styles or furniture descriptions implicitly.

Verify current Seedream mode, available reference inputs, resolution/aspect ratio and displayed cost. Use available authenticated tools/UI; never assume access. Preserve openings, table centers, furniture categories, aisle widths and camera angle. Request believable subtle surface variation without grain or warped geometry. Match exterior context only along supported sightlines. Compare the output with the source geometry and actual photos; inspect chair arms/backs/legs, glass, doors, railings and ceiling. A beautiful but spatially altered frame fails. Save exact prompt, model/mode, reference hashes, settings, job ID, actual cost and accepted output. Do not advance an unreviewed frame into video.
